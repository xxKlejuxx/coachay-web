## 1. Struktura: scoreboard współdzielony LIVE + FINISHED

Wcześniej mecz FINISHED wracał do starego, zwykłego tekstu "Wynik: X:Y".
Teraz FINISHED używa dokładnie tego samego dużego widoku co LIVE
(banery drużyn + panel wyniku), a frekwencja (Obecni/Nieobecni/Brak
odp.) jest dla FINISHED mniejsza i niżej.

```
<div class="mc-scoreboard">
    <div class="mc-sb-team mc-sb-team--our">
        <div class="mc-sb-name mc-sb-name--our">NAZWA_DRUZYNY</div>
    </div>
    <div class="mc-sb-center">
        <div class="mc-sb-label">WYNIK</div>
        <div class="mc-sb-score-row">
            <span class="mc-sb-score">2</span>
            <span class="mc-sb-dash">-</span>
            <span class="mc-sb-score">1</span>
        </div>
    </div>
    <div class="mc-sb-team mc-sb-team--opp">
        <div class="mc-sb-name mc-sb-name--opp">PRZECIWNIK</div>
    </div>
</div>
<!-- tylko dla FINISHED: -->
<div class="mc-outcome-row"><span class="mc-result-info mc-result-win">Wygrana</span></div>
<div class="mc-counts mc-counts--compact">...</div>
```

## 2. Proporcje szerokości (flex)

Baner drużyny (lewy/prawy) zwiększony o 30%, panel wyniku (środek)
zmniejszony o 60% (liczone względem wartości wyjściowych, nie względem
siebie nawzajem):

| Element | Przed | Po |
|---|---|---|
| `.mc-sb-team` (lewy/prawy baner) | `flex: 1` | `flex: 1.3` (+30%) |
| `.mc-sb-center` (środkowy panel wyniku) | `flex: 1.3` | `flex: 0.52` (-60%) |

Przy zwężeniu środka trzeba było zmniejszyć czcionki w nim, żeby się
mieściły w jednej linii (patrz tabela niżej) — a potem na życzenie
ponownie powiększyć cyfry wyniku o 2px.

## 3. Kolory i czcionki — DOKŁADNE wartości końcowe

### Banery drużyn (`.mc-sb-team--our` / `--opp`)
- Nasza drużyna: `background: linear-gradient(180deg, #1D4ED8 0%, #1E3A8A 60%, #0F172A 100%)` (granat, góra jaśniejsza)
- Przeciwnik: `background: linear-gradient(180deg, #B91C1C 0%, #7F1D1D 60%, #450A0A 100%)` (bordo)
- Border: brak (`border: none`)
- Nazwa drużyny (`.mc-sb-name--our`/`--opp`): `color: #fff`, `text-shadow: 0 2px 4px rgba(0,0,0,0.8)`, `font-size: 19px`, `font-weight: 800`, uppercase

### Panel wyniku (`.mc-sb-center`)
- Tło: `background: linear-gradient(180deg, #1E293B 0%, #020617 100%)` (ciemny granat → prawie czarny)
- **WAŻNE dla MOBILE**: pierwsza wersja używała `var(--czarny)`/`var(--bialy)` jako kolorów — na webie te zmienne CSS **nigdzie nie są zdefiniowane**, więc panel renderował się jako przezroczysty (bug, naprawiony commitem `fbec6d4`). Jeśli mobile ma analogiczny token/zmienną dla "czarny"/"biały" w swoim systemie kolorów, warto sprawdzić czy faktycznie istnieje, zanim się go użyje.
- Etykieta "WYNIK" (`.mc-sb-label`): osobna pigułka, nie zwykły tekst — `background: #020617`, `border: 1px solid #475569`, `color: #CBD5E1`, `font-size: 9px`, `padding: 1px 6px`, `border-radius: 6px`, letter-spacing .06em, uppercase
- Cyfry wyniku (`.mc-sb-score`): `color: #fff`, `text-shadow: 0 0 10px rgba(255,255,255,0.4)` (lekki glow), `font-size: 26px`, `font-weight: 900`
- Myślnik między cyframi (`.mc-sb-dash`): `color: #fff`, `font-size: 16px`, `font-weight: 900`

### Znacznik wyniku meczu — Wygrana/Przegrana/Remis (`.mc-result-win/-loss/-draw`)
Ciemny gradient + kolorowa obwódka + jasny kolorowy tekst + glow (NIE jasne tło + ciemny tekst, jak było wcześniej):
- Wygrana: `background: linear-gradient(180deg, #15803D 0%, #052E16 100%)`, `border: 1px solid #22C55E`, `color: #4ADE80`, `box-shadow: 0 0 8px rgba(34,197,94,0.4)`
- Przegrana: `background: linear-gradient(180deg, #B91C1C 0%, #450A0A 100%)`, `border: 1px solid #F87171`, `color: #FCA5A5`, `box-shadow: 0 0 8px rgba(248,113,113,0.4)`
- Remis: `background: linear-gradient(180deg, #334155 0%, #0F172A 100%)`, `border: 1px solid #64748B`, `color: #CBD5E1`, `box-shadow: 0 0 8px rgba(100,116,139,0.3)`

### Kafelki frekwencji — Obecni/Nieobecni/Brak odp. (`.mcc-g`/`.mcc-r`/`.mcc-s`)
Pastelowe gradienty (nie płaskie rgba jak wcześniej), **trzecia kafelka ("Brak odp.") jest niebieska, nie szara**:
- Obecni: `background: linear-gradient(180deg, #BBF7D0 0%, #86EFAC 100%)`
- Nieobecni: `background: linear-gradient(180deg, #FECDD3 0%, #FDA4AF 100%)`
- Brak odp.: `background: linear-gradient(180deg, #BAE6FD 0%, #93C5FD 100%)`
- Border: brak na wszystkich trzech
- Liczba (`.mcc-n`, klasy `.mn-g`/`.mn-r`/`.mn-s`) i etykieta (`.mcc-l`): **jednolity ciemny kolor niezależnie od kategorii** — `color: #0F172A` dla liczby, `color: #1E293B` dla etykiety (wcześniej każda kategoria miała swój kolor: zielony/czerwony/szary tekst — to usunięte, teraz wszystkie trzy wyglądają tak samo kolorystycznie, różni je tylko tło)
- Usunięte: wyciszanie tych kolorów dla stanu FINISHED (`.mc-finished .mcc-*`, `.mc-finished .mcc-l`) — w finalnej wersji kolory są pełne również dla zakończonego meczu, nie przygaszone

### Odznaka statusu "Zakończony" (`.mc-status-finished`)
To jest odznaka pokazywana TRENEROWI na karcie meczu (osobna od `.mc-outcome-row`/Wygrana — to dotyczy statusu meczu "zakończony", nie wyniku sportowego):
- `background: linear-gradient(180deg, #15803D 0%, #052E16 100%)` (ciemna zieleń), `color: #fff`
- Tekst to i18n `mecz.finishedBadge` = "✅ Zakończony" (checkmark już jest w tekście jako emoji, nie trzeba dodawać osobno)

### Przycisk "Cofnij zakończenie" (`.mc-btn-takeover`)
Pokazywany trenerowi przy zakończonym meczu, żeby cofnąć status:
- `background: linear-gradient(180deg, #334155 0%, #0F172A 100%)` (ciemny grafit), `border-color: #475569`, `color: #CBD5E1` (jasny srebrny)
- Tekst to i18n `mecz.revertButton` = "Cofnij zakończenie", z prefiksem "↩ "

## 4. Nowy klucz i18n

Dodany `home.scoreLabel` = "Wynik" (en: "Score") w `locales/pl.json` i `locales/en.json`, używany jako etykieta nad cyframi wyniku w panelu centralnym.

## Pytanie do MOBILE

Jeśli mobile ma analogiczny widget "najbliższy mecz" na ekranie
startowym z podobnym podziałem na dwie drużyny + wynik + frekwencja,
powyższe wartości (kolory hex/gradienty, proporcje flex, rozmiary
czcionek) można przenieść 1:1, żeby oba ekrany wyglądały tak samo.
Jeśli wymaga to innego podejścia w natywnym UI (np. inny system
designu/tokenów kolorów niż CSS), przynajmniej same wartości barw
(hex) i proporcje (30%/60%) są uniwersalne.
