# Sync #0166 — MOBILE → WEB (2026-11-06)

Uzupełnienie #0165 (kod licznika): Rafał prosi, żeby test objął zdarzenia meczu: **start, gole, przerwy,
koniec**, przy czym **gole tylko w dwóch wariantach: gole per zawodnik i gole per drużyna** (bez goli
przeciwnika w teście). W #0165 były start / przerwa / wznów / koniec / cofnij zakończenie. Tu brakujące
gole (styl `compat`, `db = firebase.firestore()`, `TS = firebase.firestore.FieldValue.serverTimestamp()`).

Model: `matchData.result = { our, opponent, updatedBy, updatedAt }`,
`matchData.playerEvents = [{ type:'GOAL', playerId, minute:null, addedBy, addedAt }]`.

- **Gol per zawodnik:** wpis w `playerEvents` + `result.our + 1` (wynik drużyny rośnie razem z golem zawodnika).
- **Gol per drużyna (bez zawodnika):** ręczna zmiana `result.our` o ±1, bez wpisu w `playerEvents`.
  Wynik drużyny nie może spaść poniżej liczby goli przypisanych zawodnikom (decyzja Rafała 2026-10-23).

```js
const evRef = (id) => db.collection('events').doc(id);

// GOL PER ZAWODNIK — dopisuje do playerEvents i zwiększa our
async function addGoal(eventId, md /* matchData z ostatniego snapshotu */, playerId, userId) {
  const playerEvents = [...(md.playerEvents || [])];
  playerEvents.push({ type: 'GOAL', playerId, minute: null, addedBy: userId, addedAt: new Date().toISOString() });
  const our = ((md.result && md.result.our) || 0) + 1;
  return evRef(eventId).update({
    'matchData.playerEvents': playerEvents,
    'matchData.result.our': our,
    'matchData.result.updatedBy': userId,
    'matchData.result.updatedAt': new Date().toISOString(),
    updatedAt: TS,
  });
}

// COFNIJ GOLA ZAWODNIKA — usuwa jego ostatniego gola i zmniejsza our
async function removeGoal(eventId, md, playerId, userId) {
  const playerEvents = [...(md.playerEvents || [])];
  let idx = -1;
  for (let i = playerEvents.length - 1; i >= 0; i--) {
    if (playerEvents[i].type === 'GOAL' && playerEvents[i].playerId === playerId) { idx = i; break; }
  }
  if (idx === -1) return;
  playerEvents.splice(idx, 1);
  const our = Math.max(0, ((md.result && md.result.our) || 0) - 1);
  return evRef(eventId).update({
    'matchData.playerEvents': playerEvents,
    'matchData.result.our': our,
    'matchData.result.updatedBy': userId,
    'matchData.result.updatedAt': new Date().toISOString(),
    updatedAt: TS,
  });
}

// GOL PER DRUŻYNA (ręcznie, bez zawodnika) — zmiana result.our o +1 / -1; tylko gdy mecz LIVE.
// Spadek poniżej liczby goli przypisanych zawodnikom jest zablokowany.
async function changeTeamScore(eventId, md, delta /* +1 | -1 */, userId) {
  const our = Math.max(0, ((md.result && md.result.our) || 0) + delta);
  if (delta < 0) {
    const assigned = (md.playerEvents || []).filter(e => e.type === 'GOAL').length;
    if (our < assigned) return { blocked: true };
  }
  return evRef(eventId).update({
    'matchData.result.our': our,
    'matchData.result.updatedBy': userId,
    'matchData.result.updatedAt': new Date().toISOString(),
    updatedAt: TS,
  });
}
```

(W appce `changeScore` obsługuje też stronę `opponent`; w teście ją pomijamy.)

**Uwaga:** w appce `addGoal` / `removeGoal` / `changeScore` robią przed zapisem dodatkowy `get()` (to
samo co pause/resume/end — 1 odczyt na akcję). W powyższej wersji `md` bierzemy z ostatniego snapshotu
listenera (zero dodatkowych odczytów). Test pokaże, czy ta różnica ma znaczenie.

## Scenariusz testu (do #0165 pkt 5)

1. Wejść na ekran meczu → **R0**.
2. **Start** → R1.
3. **Odczekać 10 min** bez akcji → R2 (oczekiwane `R2 - R1 = 0`).
4. **3 gole:** 2 × gol per zawodnik (dwóch różnych zawodników) + 1 × gol per drużyna (ręcznie) → R3.
   Oczekiwane: `R3 - R2` ≈ 3 (jeden odczyt snapshotu na każdy zapis) + ewentualnie 3, jeśli w kodzie
   jest `get()` przed zapisem.
5. **Przerwa** → **Wznów** → R4 (oczekiwane ≈ +2, +2 z `get()`).
6. **Koniec** → R5 (oczekiwane ≈ +1, +1 z `get()`).
7. Zapisy (writes) osobno: **dokładnie** liczba kliknięć (start 1 + gole 3 + przerwa 1 + wznów 1 + koniec 1 = 7),
   niezależnie od czasu trwania meczu.

**Drugie urządzenie jako widz** (rodzic, Start otwarty z kartą meczu): odczyty rosną o 1 na każdą z
powyższych akcji i **nie rosną w czasie** między akcjami. To jest dokładnie to, co chcemy potwierdzić.
