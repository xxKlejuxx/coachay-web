# Sync #0166 — MOBILE → WEB (2026-11-06)

Uzupełnienie #0165 (kod licznika): test obejmuje zdarzenia meczu **start, gole, przerwy, koniec**.
W #0165 były start / przerwa / wznów / koniec / cofnij zakończenie. Tu brakujące gole
(styl `compat`, `db = firebase.firestore()`, `TS = firebase.firestore.FieldValue.serverTimestamp()`).

## Jak rejestrujemy gole (model)

Są trzy rodzaje goli. **Gole przeciwnika rejestrujemy wyłącznie per drużyna przeciwnika, nigdy per
zawodnik przeciwnika** (nie znamy jego składu):

1. **Gol per zawodnik (nasz):** wpis w `matchData.playerEvents` + `result.our + 1`.
2. **Gol per drużyna (nasza, bez zawodnika):** ręczna zmiana `result.our` o ±1, bez wpisu w `playerEvents`.
3. **Gol drużyny przeciwnika:** ręczna zmiana `result.opponent` o ±1, bez żadnego wpisu w `playerEvents`.

`matchData.result = { our, opponent, updatedBy, updatedAt }`,
`matchData.playerEvents = [{ type:'GOAL', playerId, minute:null, addedBy, addedAt }]` — tylko nasi zawodnicy.
Wynik `our` nie może spaść poniżej liczby goli przypisanych naszym zawodnikom (decyzja Rafała 2026-10-23);
wynik `opponent` nie ma takiego ograniczenia (poza dolnym 0).

```js
const evRef = (id) => db.collection('events').doc(id);

// 1) GOL PER ZAWODNIK (nasz) — dopisuje do playerEvents i zwiększa our
async function addGoal(eventId, md /* matchData z ostatniego snapshotu */, playerId, userId) {
  const playerEvents = [...(md.playerEvents || [])];
  playerEvents.push({ type: 'GOAL', playerId, minute: null, addedBy: userId, addedAt: new Date().toISOString() });
  const our = ((md.result && md.result.our) || 0) + 1;
  return evRef(eventId).update({
    'matchData.playerEvents': playerEvents,
    'matchData.result.our': our,
    'matchData.result.updatedBy': userId,
    'matchData.result.updatedAt': new Date().toISOString(),
    updatedAt: TS,
  });
}

// COFNIJ GOLA ZAWODNIKA — usuwa jego ostatniego gola i zmniejsza our
async function removeGoal(eventId, md, playerId, userId) {
  const playerEvents = [...(md.playerEvents || [])];
  let idx = -1;
  for (let i = playerEvents.length - 1; i >= 0; i--) {
    if (playerEvents[i].type === 'GOAL' && playerEvents[i].playerId === playerId) { idx = i; break; }
  }
  if (idx === -1) return;
  playerEvents.splice(idx, 1);
  const our = Math.max(0, ((md.result && md.result.our) || 0) - 1);
  return evRef(eventId).update({
    'matchData.playerEvents': playerEvents,
    'matchData.result.our': our,
    'matchData.result.updatedBy': userId,
    'matchData.result.updatedAt': new Date().toISOString(),
    updatedAt: TS,
  });
}

// 2) GOL PER DRUŻYNA (nasza) i 3) GOL DRUŻYNY PRZECIWNIKA — ręczna zmiana wyniku +1 / -1.
// side: 'our' (gol drużyny bez zawodnika) | 'opponent' (gol przeciwnika, zawsze per drużyna).
async function changeScore(eventId, md, side, delta, userId) {
  const result = { our: (md.result && md.result.our) || 0, opponent: (md.result && md.result.opponent) || 0 };
  const next = Math.max(0, result[side] + delta);
  if (side === 'our' && delta < 0) {
    const assigned = (md.playerEvents || []).filter(e => e.type === 'GOAL').length;
    if (next < assigned) return { blocked: true };   // nie schodzimy poniżej goli przypisanych zawodnikom
  }
  result[side] = next;
  return evRef(eventId).update({
    'matchData.result.our': result.our,
    'matchData.result.opponent': result.opponent,
    'matchData.result.updatedBy': userId,
    'matchData.result.updatedAt': new Date().toISOString(),
    updatedAt: TS,
  });
}
```

**Uwaga:** w appce `addGoal` / `removeGoal` / `changeScore` robią przed zapisem dodatkowy `get()` (to
samo co pause/resume/end — 1 odczyt na akcję). W powyższej wersji `md` bierzemy z ostatniego snapshotu
listenera (zero dodatkowych odczytów). Test pokaże, czy ta różnica ma znaczenie.

## Scenariusz testu (do #0165 pkt 5)

1. Wejść na ekran meczu → **R0**.
2. **Start** → R1.
3. **Odczekać 10 min** bez akcji → R2 (oczekiwane `R2 - R1 = 0`).
4. **4 gole:** 2 × gol per zawodnik (dwóch różnych zawodników) + 1 × gol per drużyna (nasza, ręcznie)
   + 1 × gol drużyny przeciwnika (ręcznie) → R3.
   Oczekiwane: `R3 - R2` ≈ 4 (jeden odczyt snapshotu na każdy zapis) + ewentualnie 4, jeśli w kodzie
   jest `get()` przed zapisem.
5. **Przerwa** → **Wznów** → R4 (oczekiwane ≈ +2, +2 z `get()`).
6. **Koniec** → R5 (oczekiwane ≈ +1, +1 z `get()`).
7. Zapisy (writes) osobno: **dokładnie** liczba kliknięć (start 1 + gole 4 + przerwa 1 + wznów 1 + koniec 1 = 8),
   niezależnie od czasu trwania meczu.

**Drugie urządzenie jako widz** (rodzic, Start otwarty z kartą meczu): odczyty rosną o 1 na każdą z
powyższych akcji i **nie rosną w czasie** między akcjami. To jest dokładnie to, co chcemy potwierdzić.
