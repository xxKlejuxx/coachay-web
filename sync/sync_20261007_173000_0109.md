# Sync #0109 — WEB → MOBILE (2026-10-07 17:30)

Uzupełnienie #0107 — tam opisaliśmy głównie logowanie telefonem, zabrakło rejestracji. Pełny obraz:

## Rejestracja telefonem na WEB — jak faktycznie działa

**Telefon NIE jest samodzielną metodą rejestracji** — działa tylko jako jedna z metod potwierdzenia tożsamości
**w ramach rejestracji z kodem zaproszenia** (`form-kod`, zakładka metody „phone" przy `switchMethodTab`).
Czyli: user musi mieć 6-znakowy kod od trenera (RODZIC/ZAWODNIK/OBSERWATOR/TRENER_POMOCNICZY), wpisać go, i wtedy
w kroku metody rejestracji może wybrać telefon zamiast email/Google/Apple.

Przebieg (`doRegisterPhoneSend` → `doRegisterPhoneConfirm` → `_finishCodeRegistration` → `_createFirestoreDocsFromPending`):
1. User wpisuje numer (`reg-phone`), `doRegisterPhoneSend()` wysyła SMS (`signInWithPhoneNumber` + niewidoczny reCAPTCHA).
2. User wpisuje 6-cyfrowy kod SMS, `doRegisterPhoneConfirm()` go potwierdza (`confirmationResult.confirm(code)`).
3. **Natychmiast po potwierdzeniu SMS** (`isPhone=true`) — bez weryfikacji e-mail, bez żadnego dodatkowego kroku —
   `_finishCodeRegistration` tworzy od razu dokumenty w Firestore (`users`, `memberships`, `authIndex`, ewentualnie
   zawodnik/klub wg typu kodu) i user jest przekierowany na `start.html`. To różni się od rejestracji e-mailem,
   gdzie jest pośredni krok `sendEmailVerification` + ekran „potwierdź mail" (`isPhone`/`isGoogle` pomijają ten krok,
   bo numer telefonu jest już zweryfikowany samym SMS-em).
4. `users.phone` = pełny numer w formacie z pkt „Format numeru" z #0107 (domyślnie `+48` + cyfry, bez selektora kraju).

**Czego NIE ma:** rejestracji głównego trenera (`doRegisterTrainer`, tworzenie nowego klubu) przez telefon — to
wyłącznie e-mail+hasło. Telefon jest dostępny tylko dla kodów zaproszenia (RODZIC/ZAWODNIK/OBSERWATOR/TRENER_POMOCNICZY),
nie dla zakładania nowego klubu.

**Podsumowując odpowiedź na #0105 pytanie 1 (logowanie) + to uzupełnienie (rejestracja):** na WEB telefon to w pełni
działająca, produkcyjna ścieżka — ale wyłącznie w kontekście „dołącz kodem do istniejącej drużyny", nigdy jako
pierwszy krok zakładania konta/klubu od zera.
