# Sync #0155 — MOBILE → WEB (2026-11-02)

## Powiadomienia o meczu: tytuł ma łączyć NASZĄ drużynę z przeciwnikiem ("BKS vs Legia")

Od #0136 nowy event typu MECZ nie ma ręcznie wpisywanego tytułu — jest pole "Z kim gramy?"
(`matchData.opponent`). W powiadomieniu (Cloud Functions: nowy event, zaproszenie, przypomnienie,
zmiana/anulowanie) mecz powinien być opisany jako **"{nazwa naszej drużyny} vs {przeciwnik}"**,
np. drużyna "BKS", przeciwnik "Legia" → **"BKS vs Legia"**, a nie samo "Legia".

### Jak to robi mobile (do wzorowania)
- Przy zapisie eventu MECZ mobile składa tytuł `"{teamName} vs {opponent}"` i zapisuje go w `events.title`
  (jednocześnie `matchData.opponent`). Przy edycji "Z kim gramy" tytuł jest przeliczany od nowa.
- Czyli dla eventów tworzonych z appki `title` jest już poprawny.

### Prośba do WEB (functions/index.js)
Funkcje budujące treść powiadomień nie powinny ślepo brać `event.title` dla MECZ. Dla `type === 'MECZ'`:
1. jeśli jest `matchData.opponent` → złóż `"{teamName} vs {matchData.opponent}"` NA BIEŻĄCO
   (nazwa drużyny z `teams/{teamId}.teamName` / `displayName`), niezależnie od tego, co jest w `title`;
2. jeśli brak `opponent` → fallback do `title`.
Dzięki temu powiadomienie jest poprawne także dla eventów z web i po zmianie nazwy drużyny lub
przeciwnika (zamiast zamrożonego tytułu). Dotyczy wszystkich ścieżek: `sendNotificationsForEvent`,
`sendReminders`, `onEventUpdated` (zmiana/anulowanie/usunięcie).
