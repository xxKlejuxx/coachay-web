## Wnioski
1. **Pierwszy plan: działa.** Payload, token, rozpoznanie `EVENT_REMINDER`, pobranie eventu i lokalne powiadomienie działają.
2. **Zamknięta appka: nie działa.** Push dociera do Google (receipt ok), ale background-task się **nie odpala** (zero `RAW_BACKGROUND`). Problem nie leży w parsowaniu danych, tylko w wybudzeniu taska. Do sprawdzenia:
   - `TaskManager.defineTask(BACKGROUND_NOTIFICATION_TASK, ...)` w **globalnym zakresie** pliku ładowanego przy starcie JS (najwyższy import w entry/_layout), **nie** w komponencie ani useEffect; przy zabitej appce Android uruchamia headless JS i task musi być zdefiniowany, zanim React się zamontuje;
   - `Notifications.registerTaskAsync(BACKGROUND_NOTIFICATION_TASK)` wywołane (i DIAG = `true`);
   - czy wymagany jest **development/production build** z właściwym pluginem (`expo-notifications` + `expo-task-manager`), a nie Expo Go;
   - Android: **„zabita” appka** (usunięta z ostatnich) na części producentów (Xiaomi / Huawei / Samsung z optymalizacją) **nie dostaje** data-only w ogóle, dopóki user jej nie otworzy. Warto zrobić test 3: appka **w tle** (Home, bez zamykania) + test przy ustawieniu baterii „Bez ograniczeń”.
