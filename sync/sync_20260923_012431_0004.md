## Temat: Jak podłączyć te same uprawnienia (GitHub MCP + terminal) na drugim komputerze (np. Mac)

Kontekst: na komputerze Windows Rafała (`laptop-a4lj3ni3`) mamy pełny dostęp: GitHub (odczyt+zapis do `coachay-web`) i prawdziwy terminal/Firebase CLI, oba przez lokalne serwery MCP skonfigurowane w `claude_desktop_config.json` aplikacji Claude Desktop. Rafał chciał wiedzieć czy to samo da się zrobić na Macu.

### Skąd te uprawnienia się biorą

Plik configu na Windows: `%APPDATA%\Claude\claude_desktop_config.json`, sekcja `mcpServers`:

- **`github`** — `npx -y @modelcontextprotocol/server-github` (owinięte w `cmd /c` na Windows), z tokenem w zmiennej `GITHUB_PERSONAL_ACCESS_TOKEN` (fine-grained PAT, scope Contents R/W na `coachay-web`)
- **`desktop-commander`** — `npx -y @wonderwhy-er/desktop-commander@latest` — to daje realny terminal (PowerShell) i dostęp do plików na komputerze, surfaced jako `mcp__remote-devices__desktop-commander__*`. **Uwaga dla następnej sesji: na tym urządzeniu nie ma `device_bash` — jest tylko `desktop-commander`, inny mechanizm, inne narzędzia.**

Oba serwery są widoczne przez `get_device_info().localMcpServers` gdy sesja jest podłączona do tego komputera.

### Jak zrobić to samo na Macu

1. Plik configu: `~/Library/Application Support/Claude/claude_desktop_config.json` (analogiczna lokalizacja jak na Windows, inna ścieżka bo macOS)
2. Ta sama struktura `mcpServers`, ale **bez** `cmd /c` — na macOS `command` to bezpośrednio `npx`:
```json
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "<nowy, osobny token dla Maca>" }
    },
    "desktop-commander": {
      "command": "npx",
      "args": ["-y", "@wonderwhy-er/desktop-commander@latest"]
    }
  }
}
```
3. Wymaga Node.js zainstalowanego na Macu (żeby `npx` istniało)
4. Osobny token PAT dla Maca (nie ten sam co na Windows) — ten z Windows był już raz wklejony w plaintext na czacie, więc nie warto go mnożyć na kolejne urządzenia
5. Pełny restart aplikacji Claude Desktop po zapisaniu configu
6. Jeśli chce też dostęp do plików/terminala na Macu (tak jak na Windows) — sklonować `coachay-web` lokalnie tam i podłączyć ten folder do sesji

### Rekomendacja

Windows już działa w pełni (GitHub + terminal + Firebase `coachay-5c3c9` produkcja). Duplikowanie configu na Macu ma sens tylko jeśli Rafał faktycznie pracuje z obu komputerów naprzemiennie — inaczej to dodatkowa rzecz do utrzymania w synchronizacji (dwa tokeny, dwa lokalne clone repo).
