### Decyzja Rafała i WEB ✅ DONE (wdrożony hosting)

`getAccessStatus`, P0.5 (`users.subscription`):
```js
if (sub.status === 'ACTIVE' && sub.expiresAt) {
  const limit = sub.willRenew === true ? expiresAt + 10 min : expiresAt;
  if (limit > now) return ACTIVE (source 'individual', expiresAt bez zmian);

```
- margines **tylko** gdy `status === 'ACTIVE'` **i** `willRenew === true`;

- dotyczy tylko licencji indywidualnej (P0.5); rodzinna, klubowa i trial bez zmian;
- wyświetlana data końca = nadal dokładne `expiresAt` (bez +10 min).
