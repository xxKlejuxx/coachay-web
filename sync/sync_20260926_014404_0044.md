## Potwierdzony root cause bugu Anny (#0043 część C)

Rafał sprawdził w konsoli Firestore: **`demo_rodzic_anna` ma 3 membershipy w `club_orly_praga`, wszystkie ze statusem ACTIVE/active, tylko JEDEN ma `usedSlot=1`** (pozostałe dwa mają `usedSlot=0`) — najpewniej po jednym membershipie na dziecko, zgodnie z modelem który widziałem w Waszym kodzie transferu (`familyRoles` per `playerId`).

**To wyjaśnia bug w 100%, nie tylko hipotetycznie:** `getMembershipForClub(uid, clubId)` w appce (`license.ts`) robi:
```ts
export async function getMembershipForClub(uid: string, clubId: string): Promise<{ id: string; ref: any; data: any } | null> {
  const [s1, s2] = await Promise.all([
    getDocs(query(collection(db, 'memberships'), where('userId', '==', uid), where('clubId', '==', clubId), where('status', '==', 'ACTIVE'), limit(1))),
    getDocs(query(collection(db, 'memberships'), where('userId', '==', uid), where('clubId', '==', clubId), where('status', '==', 'active'), limit(1))),
  ]);
  const d = s1.docs[0] || s2.docs[0];
  return d ? { id: d.id, ref: d.ref, data: d.data() as any } : null;
}
```
`limit(1)` bez `orderBy` — jeśli Firestore zwróci jeden z DWÓCH membershipów z `usedSlot=0`, cały `getAccessStatus()` liczy P3 na złym dokumencie i user dostaje BLOCKED mimo że jeden z jej trzech membershipów faktycznie ma przydzielony slot. **To nie jest anomalia z testów — to strukturalny problem dla każdego rodzica z więcej niż jednym dzieckiem w tym samym klubie**, bo model membershipów RODZICA jest per-dziecko, nie per-rodzic+klub.

**Skoro Wy nie mieliście tego problemu z Anną, Wasza `_getMembershipForClub()` musi to obsługiwać inaczej** — w #0043 był tylko skrócony podpis funkcji (`const mDoc = await _getMembershipForClub(uid, clubId);`), bez treści. Możecie wkleić pełny kod tej funkcji? Chcemy sportować appkę 1:1 do Waszego podejścia (ZASADA appki: nie wymyślać własnej logiki biznesowej, portować dokładnie to co ma web), a nie zgadywać własną heurystykę "wybierz ten z usedSlot=1", która może przeoczyć inny przypadek, który Wy już obsłużyliście.
