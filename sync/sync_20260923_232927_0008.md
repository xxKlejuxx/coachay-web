## 1. Nowa Cloud Function: `reconcileClubSlots` — ✅ DONE (commit 47ac817, wdrożona)

**Problem:** `clubs.license.used` jest wszędzie zmieniane tylko przyrostowo (+1/−1). Każdy pominięty krok (ręczna edycja, skrypt, błąd) rozjeżdżał licznik na stałe. Przykład: `club_orly_praga` miał `used = 2/2`, a slot miał faktycznie tylko 1 membership. Przez to przydział slotów przy logowaniu i w nocy uznawał pulę za pełną, a Jan/Anna nie mogli dostać wolnego miejsca.

**Rozwiązanie:** funkcja zaplanowana na **02:30 Europe/Warsaw**, przed `assignExpiredTrialSlotsV2` (03:00), żeby przydział pracował na prawdziwym stanie.

Zakres: każdy klub z **aktywną** licencją (`license.valid_until > teraz`) i `license.total > 0`.

| Sprawdzenie | Działanie |
|---|---|
| `usedSlot == 1` przy statusie BLOCKED / REMOVED / INACTIVE / DELETE | auto: `usedSlot = 0` |
| `usedSlot == 1` przy roli ZAWODNIK / KIBIC | auto: `usedSlot = 0` |
| ta sama osoba (`userId`) z 2+ slotami w klubie | auto: zostaje najstarszy przydział, reszta `usedSlot = 0` |
| membership klubu bez pola `usedSlot` | auto: `usedSlot = 0` |
| `license.used` ≠ faktyczna liczba slotów | auto: `license.used` = faktyczna liczba + aktualizacja `cachedClubLicense` na memberships klubu |
| więcej slotów niż `license.total` | tylko log (decyzja ręczna) |
| scope `trainers_only`, a RODZIC ma slot | tylko log |
| `maxOneParentPerChild` naruszone | tylko log |

Kluby z wygasłą licencją nadal obsługuje `updateClubLicenseStatuses` (06:00): zerowanie `used`/`total` i slotów.

**Pierwsze uruchomienie (ręczne, 23.09 23:27 UTC):**
```
✓ reconcileClubSlots: club_orly_praga — license.used 2 → 1 (total 2), wyzerowano 0 membership(ów)
✅ sprawdzono 1 klubów z aktywną licencją, poprawiono 1, wyzerowano 0 slotów
```
W `club_orly_praga` jest teraz 1 wolne miejsce. Przydzieli je nocny `assignExpiredTrialSlotsV2` (trener główny ma pierwszeństwo) albo `claimSlot` przy logowaniu.

**Dla APP:** nic nie trzeba zmieniać. Jeśli APP czyta `cachedClubLicense.used/total` do wyświetlania stanu puli, po korekcie dostanie poprawne wartości.
