Dobra architektura to ważny temat — odpowiem konkretnie.

1. Powiadomienia i potwierdzanie obecności
Problem: Za dużo miejsc racji.

Jak to działa w 2026 na iOS/Android:
Push notification z web (PWA) = tylko tap → otwiera apkę. Nie ma action buttons jak w natywnych appkach (iOS/Android native mogą mieć "Tak/Nie" bezpośrednio w notyfikacji, ale PWA — nie).

Rekomendacja:

Push notification → tylko info (auto-read po otwarciu), zero akcji
Potwierdzanie obecności → tylko start.html (dashboard)
Na szczegółach eventu → opcjonalnie, ale wtórnie
Panel dzwonka (🔔) → lista informacyjna, nie centrum akcji
Zysk: prostota. Użytkownik wie: "muszę wejść na Start żeby coś potwierdzić".

2. Zawodnicy — druzyna.html vs klub.html
Aktualna architektura jest poprawna koncepcyjnie, ale nazwa i komunikacja są mylące.

Zasada dwóch warstw:

druzyna.html	klub.html
Cel	Operacyjny (dziś, mecz, lista)	Administracyjny (CRUD)
Widzi	Tylko aktywni	Wszyscy
Akcje	Obecność, filtry	Dodaj / Edytuj / Blokuj / Przenieś
Rekomendacja: Usuń "Dodaj zawodnika" z druzyna.html. Zostaw tylko widok + szybkie akcje (obecność, absencja). Jedno miejsce do zarządzania = klub.html.

3. Trenerzy — osobny ekran czy w klub.html?
Aktualne: trenerzy.html = widok + dodawanie + zarządzanie. Dużo w jednym.

Rekomendacja — ta sama zasada dwóch warstw:

trenerzy.html = widok zespołu trenerskiego (wszyscy widzą, kto jest trenerem, ich bio, kontakt). Dodawanie (zaproszenie kodem) — zostaje tutaj.
klub.html = zarządzanie trenerami (blokada, usunięcie, zmiana drużyny, admin role) — tak samo jak zawodnikami.
Czyli:

trenerzy.html ≈ druzyna.html  (widok operacyjny)
klub.html     = centrum zarządzania wszystkim (zawodnicy + trenerzy)

Podsumowanie — spójna reguła
"Widzisz na ekranie zespołu, zarządzasz w Klubie."

To jest zasada którą rozumie każdy użytkownik. Spójne z tym jak działają Spond, TeamSnap, Heja w 2026 — jedna zakładka "drużyna" (operacyjna), jeden panel "admin/klub" (zarządzanie).

// Przedłuż trial wszystkich userów w danym klubie o 30 dni
async function extendTrials(clubId, days) {
  const users = await db.collection('users')
    .where(`clubs_trial.${clubId}`, '!=', null).get();
  
  const batch = db.batch();
  users.forEach(doc => {
    const current = doc.data().clubs_trial[clubId].toDate();
    const extended = new Date(Math.max(current, new Date()));
    extended.setDate(extended.getDate() + days);
    batch.update(doc.ref, {
      [`clubs_trial.${clubId}`]: admin.firestore.Timestamp.fromDate(extended)
    });
  });
  await batch.commit();
}

const GRACE_DAYS = 7;

function getAccessStatus(uid, clubId, user, accessRights) {
  const now = new Date();
  const graceCutoff = new Date(now - GRACE_DAYS * 24 * 60 * 60 * 1000);

  // 1. Opłacony dostęp (personal_sub / club_license / family_slot)
  const right = accessRights.find(r => r.uid === uid && r.club_id === clubId);
  if (right) {
    const validUntil = right.valid_until.toDate();
    if (validUntil > now)        return { status: 'ACTIVE',  source: right.source };
    if (validUntil > graceCutoff) return { status: 'GRACE',  source: right.source };
  }

  // 2. Trial
  const trialEnd = user.clubs_trial?.[clubId]?.toDate();
  if (trialEnd) {
    if (trialEnd > now)         return { status: 'TRIAL',  source: 'trial' };
    if (trialEnd > graceCutoff) return { status: 'GRACE',  source: 'trial' };
  }

  return { status: 'EXPIRED', source: null };
}

// Przy odnowieniu subskrypcji (webhook z tPay / RevenueCat):
async function renewAccess(uid, clubId, source, durationDays) {
  const rightRef = db.collection('access_rights')
    .where('uid', '==', uid)
    .where('club_id', '==', clubId);

  const existing = await rightRef.get();
  const now = new Date();

  let newValidUntil;

  if (!existing.empty) {
    const current = existing.docs[0].data().valid_until.toDate();
    
    // Baza to valid_until — NIE today
    // Jeśli valid_until już w przeszłości (grace), liczymy od valid_until
    newValidUntil = new Date(current);
    newValidUntil.setDate(newValidUntil.getDate() + durationDays);
  } else {
    // Nowy user — liczymy od teraz
    newValidUntil = new Date(now);
    newValidUntil.setDate(newValidUntil.getDate() + durationDays);
  }

  // Zapisz
  await db.collection('access_rights').add({
    uid, club_id: clubId, source,
    valid_until: admin.firestore.Timestamp.fromDate(newValidUntil),
    renewed_at: admin.firestore.Timestamp.fromDate(now)
  });
}
